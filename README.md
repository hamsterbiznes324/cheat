# TG Desktop — мод для Minecraft 1.21.11 (Fabric)

Плавающие окна в стиле iOS/VR прямо внутри игры: **Telegram**, **Discord**, **YouTube** и полноценный **браузер** (настоящий Chromium через библиотеку Rinku).

- Окна перетаскиваются за шапку, растягиваются за правый нижний угол, сворачиваются и закрываются.
- Снизу — док с иконками приложений (как на iPhone/Mac) и **домашняя полоска**: клик по ней сворачивает все окна и возвращает в игру.
- Игра **не встаёт на паузу**, когда рабочий стол открыт.
- Закрыл рабочий стол (J или Esc) — окна продолжают работать в фоне: видео играет со звуком, сессии Telegram/Discord не слетают.
- Позиции окон и открытые страницы сохраняются в `config/tgdesktop.json` и восстанавливаются после перезапуска игры.

## Управление

| Действие | Как |
|---|---|
| Открыть/закрыть рабочий стол | **J** (меняется в Настройки → Управление) |
| Открыть приложение | Клик по иконке в доке снизу |
| Перетащить окно | Зажать шапку окна и тянуть |
| Изменить размер | Тянуть за правый нижний уголок |
| Свернуть в док | Кнопка **–** в шапке |
| Закрыть приложение | Кнопка **×** в шапке |
| Свернуть всё и выйти в игру | Клик по белой полоске в самом низу экрана |
| Адресная строка (в «Browser») | Клик по полю, Enter — перейти, Ctrl+V — вставить ссылку |

## Что потребуется для игры

1. **Minecraft Java 1.21.11**
2. **Fabric Loader** 0.18.3+ (ставится с fabricmc.net или через Prism Launcher)
3. **Fabric API** (0.140.2 или новее для 1.21.11) — мод с Modrinth
4. **Rinku** 3.0.1+ (Fabric, MC 1.21.11) — мод с Modrinth/CurseForge, это движок Chromium
5. Собранный `tgdesktop-1.0.0.jar` из этого проекта

Все три jar (Fabric API, Rinku, tgdesktop) кладутся в папку `mods`.

> При первом запуске Rinku покажет экран загрузки и скачает Chromium (~200 МБ) — это нормально, ждём один раз.
> Windows 11 x64 — полностью поддерживается. Если антивирус ругнётся на файлы Rinku — добавь папку игры в исключения.

## Как собрать jar на Windows 11

### Шаг 1. Установи JDK 21
Скачай и установи **Temurin 21** (Adoptium): https://adoptium.net/temurin/releases/?version=21
При установке отметь галочку «Set JAVA_HOME variable» (или настрой вручную).

Проверка в командной строке:
```
java -version
```
Должно показать `21.x.x`.

### Шаг 2. Собери мод

**Вариант А — через IntelliJ IDEA (самый простой):**
1. Установи бесплатную IntelliJ IDEA Community: https://www.jetbrains.com/idea/download/
2. File → Open → выбери папку `TGDesktop`.
3. IDEA сама подтянет Gradle и скачает всё нужное (первый раз — несколько минут).
4. Справа открой панель Gradle → `tgdesktop` → `Tasks` → `build` → `build`.

**Вариант Б — через командную строку:**
1. Установи Gradle 9.5+ (https://gradle.org/install/ — проще всего `winget install Gradle.Gradle`).
2. В папке проекта один раз выполни:
   ```
   gradle wrapper
   ```
3. Затем собирай:
   ```
   gradlew.bat build
   ```

### Шаг 3. Забери jar
Готовый мод будет здесь:
```
TGDesktop\build\libs\tgdesktop-1.0.0.jar
```
Кинь его в `%appdata%\.minecraft\mods` вместе с Fabric API и Rinku.

## Если сборка ругается

- **`Unsupported Java` / ошибки про Java** — Gradle запущен не под JDK 21. Проверь `java -version` и JAVA_HOME.
- **Не качаются зависимости** — нужен интернет; проверь, что не блокируют maven.fabricmc.net и keksuccino.github.io.
- **Игра не запускается с модом** — смотри `latest.log` в папке `logs`: чаще всего не хватает Rinku или Fabric API нужной версии.
- Пришли текст ошибки автору мода — чинится быстро.

## Важные ограничения (так устроен Chromium в игре)

- **Discord**: текст, каналы, чаты — работают. Голосовые и видеозвонки — нет (нет доступа к микрофону/камере из игры).
- **Telegram**: полностью рабочий Web-клиент (вход по номеру + коду).
- **YouTube**: видео со звуком работают. Netflix и другие DRM-сервисы — нет.
- Это клиентский мод: на любом сервере работает без установки на сервер.

## Структура кода

```
com.tgdesktop
├── TGDesktopClient      — точка входа, клавиша J
├── DesktopScreen        — рабочий стол: окна, док, домашняя полоска, ввод
├── DesktopState         — список окон, фокус, сохранение в config/tgdesktop.json
├── AppWindow            — окно: шапка, кнопки, перетаскивание, ресайз
├── BrowserAppContent    — Chromium через Rinku: рендер текстуры, мышь/клавиатура
├── UrlField             — адресная строка браузера
├── DockApp              — приложения дока (TG / Discord / YouTube / Browser)
└── RoundedDraw          — скруглённые прямоугольники без текстур
```
